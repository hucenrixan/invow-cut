Machine settings

Size wrong? Cut the test square (20 mm). If it measures e.g. 19.6 mm, set steps = 40 × 20 ÷ 19.6.
Test “F” mirrored or rotated? Change Flip across / Flip feed / Swap X/Y until it is correct.

Help

Drag objects to move. Drag the blue square to resize. Drag empty space to pan, mouse wheel to zoom. Arrow keys nudge 1 mm (Shift = 10 mm). Del deletes, Ctrl+D duplicates, Ctrl+Z undo.

Before cutting: Reset the cutter, load vinyl, rollers down, press Origin, not paused. Close SignMaster (only one program can use the port).
